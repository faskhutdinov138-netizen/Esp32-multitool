Мультифункциональное устройство на ESP32

Многофункциональное устройство на базе ESP32-2432S028 (CYD) с 
сенсорным дисплеем 2.8", BLE HID и веб-интерфейсом.

![Главное меню](images/menu.jpg)

## ✨ Возможности

- 📱 Сенсорный TFT-дисплей 240×320
- 🧮 Калькулятор с историей
- ✖️ Таблица умножения
- 🎮 Игры: Тетрис, Flappy Bird
- ⏱️ Секундомер и таймер
- 💻 PC Macro — эмуляция клавиатуры через BLE HID
- 🌐 Веб-сервер для шпаргалок (WiFi AP)
- 🎨 6 тем оформления + 8 обоев
- 🟢 Matrix-анимация

## 🛠️ Железо

- ESP32-2432S028 (Cheap Yellow Display / CYD)
- Дисплей: ILI9341 240×320 (SPI)
- Тач: XPT2046 (SPI)

## 📚 Библиотеки

Установите через Library Manager:
- TFT_eSPI (2.5.44+)
- XPT2046_Touchscreen (1.4+)
- ESP32 BLE HID Combo (0.3.1+)

## ⚙️ Настройки Arduino IDE

**Tools → Board:** ESP32 Dev Module
**Tools → Partition Scheme:** Huge APP (3MB No OTA/1MB SPIFFS)
**Tools → Upload Speed:** 921600

⚠️ Без "Huge APP" скетч не влезет (занимает ~1.6 MB).

## 🚀 Использование

1. Прошейте скетч через Arduino IDE
2. Устройство создаст WiFi-точку `Linux` (пароль `12345678`)
3. Откройте `192.168.4.1` в браузере для редактирования шпаргалок
4. Для PC Macro подключитесь к BLE-устройству `ESP32 BLE Combo` на ПК
